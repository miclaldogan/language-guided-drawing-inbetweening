# Reports

Reserve this directory for reviewed course progress reports, pilot summaries, experiment analyses, and the final evaluation. No reports or empirical results exist yet.

Each report should identify its question, date, author, code commit, model/config/data/split revisions, protocol, measured evidence, exclusions, limitations, and next decision. Link approved artifact locations rather than committing media, weights, raw logs, private subject details, or tracking exports. The final report should distinguish validation-driven choices from held-out test results.
