# Cue — Typography System

The current mockup uses system fonts so the page opens offline and rendering stays consistent without a font download.

| Role | Family | Use |
|---|---|---|
| Display | Georgia / Iowan Old Style / Times | Editorial landing statements, screen titles, job names |
| Interface | Arial / Helvetica | Forms, button labels, descriptive copy |
| Metadata | SF Mono / Consolas / Liberation Mono | Frame counts, specimen IDs, state annotations |

## Rules

- Display faces stay regular weight; scale and line spacing create the editorial voice.
- Interface labels use sentence case except for intentionally technical specimen annotations.
- All user-facing workflow copy remains English, as specified in the screen plan.
- Small text uses charcoal or a muted neutral on paper. Sage and copper are used for large emphasis, icons, borders, and action fills with a tested ink foreground.
- Numeric frame and job metadata use tabular alignment where available.
