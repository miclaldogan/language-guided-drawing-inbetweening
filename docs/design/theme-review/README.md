# Cue — Theme Review

Five interactive color directions applied to the same art-led landing page. Choose a theme from the palette strip to compare its full page treatment.

## Preview

Open `index.html` in a current browser. No build step or server is required.

## Palettes

The five options correspond to the color suggestions in the comparison: Aubergine Archive, Night Print, Petrol Atelier, Burgundy Herbarium, and Terracotta Frequency. Each palette uses a dominant field, warm paper surfaces, two accents, and a charcoal text color.
