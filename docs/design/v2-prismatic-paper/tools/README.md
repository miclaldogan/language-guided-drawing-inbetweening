# Preview generator

SVG source for the style tiles and previews (python3 tools/generate_previews.py <outdir>). Rendering used rsvg-convert with Fraunces (opsz 72, SOFT 50, WONK 0, static weights 600/800 renamed "Fraunces Display"/"Fraunces Display Bold") and Manrope installed through a private fontconfig. Not production code.
