# Cue design artifacts

## Current mockup

[`v11-cue-sheet/`](v11-cue-sheet/index.html) is the current redesign: a public page whose hero is a working cue sheet, and six interactive studio screens ([`app.html`](v11-cue-sheet/app.html)) with every state from the UX plan. See its [README](v11-cue-sheet/README.md) and [design direction](v11-cue-sheet/DESIGN_DIRECTION.md).

## Previous mockup

[`v10-bordo-herbaryum/`](v10-bordo-herbaryum/index.html) was the previous full-site redesign. It applies the selected Bordo Herbaryum palette to the public landing page, sign-in, six product screens, and an independent Wave-Line lab. Its [design direction](v10-bordo-herbaryum/DESIGN_DIRECTION.md), [README](v10-bordo-herbaryum/README.md), and [tokens](v10-bordo-herbaryum/tokens.json) describe the current visual system.

The active product flow follows the [screen-by-screen UX plan](CUE_SCREEN_BY_SCREEN_UX_PLAN.md), [user flows](CUE_USER_FLOWS.md), [requirements traceability](CUE_REQUIREMENTS_UI_TRACEABILITY.md), and the reviewed database proposal at `../architecture/database-and-diagrams-v2/`.
