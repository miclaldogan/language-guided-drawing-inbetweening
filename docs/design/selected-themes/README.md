# Cue — Selected Theme Directions

Two complete versions of the Cue landing page, prepared to compare the **Bordo Herbaryum** and **Kiremit Frekans** palettes. Each direction gets its own hero art treatment: botanical engraving for the first, wave and frequency marks for the second.

## Preview

Open `index.html` in a current browser and choose either theme from the palette strip. The page layout stays consistent while the copy, colors, and illustration marks shift to match the selected art direction. You can also open the Kiremit Frekans version directly at `index.html?theme=frequency`.

No build step or server is required.
