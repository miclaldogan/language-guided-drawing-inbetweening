# Navbar Comparison

Both candidates were rendered inside the full S4 page, not as strips: `navbar-comparison/navbar-A-purple_s4.png` and `navbar-B-cream_s4.png`. Same height (64), wordmark scale (24), left padding (40), separators and account control layout.

| | A Deep purple (recommended) | B Warm paper |
|---|---|---|
| Fill | `#431452`, 6% grain | `#FFFAF0` with 1 px ink 16% bottom rule |
| Wordmark | paper-white, end ticks gold | ink, end ticks purple |
| Active item | paper-white text, 3 px gold bar | ink text, 3 px purple bar |
| Account | gold avatar with ink initial, paper-white email, chevron | purple avatar, ink email |
| On gold ground | Strong separation; gold and purple are the brand pair | Cream bar next to saturated gold feels pasted; weaker edge |
| On paper ground | Clear frame; gold rule below completes it | Merges with the sheet; needs the rule |
| Contrast | paper-white on purple 13.8:1; gold on purple 8.1:1 | ink on paper-white 15.5:1 |
| Identity | Distinct, recognisable in a thumbnail | Refined, but looks like many other tools |

**Recommendation: A.** It gives Cue a real frame, uses gold sparingly as an indicator, and keeps the wordmark readable at small size. B remains an option for a calmer variant but is not recommended.

Navigation items are unchanged: wordmark (home), Library, and the account menu (Log out). "New animation" is a page action, not a nav item. The stepper on S3–S6 is page-level.
