# Cue — Bordo Herbaryum

A full visual redesign using the selected Bordo Herbaryum palette. This is an independent, local, interactive mockup; it does not connect to the API, database, authentication service, or generation worker.

## Preview

Open `index.html` directly in a browser. No build step, network font, or server is required.

## Included views

- Public landing page and sign-in
- Animation library
- Start/end drawing upload
- Optional English motion prompt and plan approval
- Generation status and result playback/export views
- An isolated Wave-Line study with adjustable line controls

## Product behavior preserved

The screen flow and state vocabulary follow the requirements and database proposal. Generation states are queued, running, done, failed, and cancelled. The status view does not invent percent completion or an ETA. Mock data and prototype-only actions are clearly labelled in the interface.
