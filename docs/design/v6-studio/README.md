# Cue Studio — V6 mockup

An independent product mockup direction for Cue, based on the project’s six core user screens and the Wave-Line study. It does not replace or delete earlier explorations.

## Open

Open `index.html` in a current browser. No package install or build step is needed.

## What's included

- Six connected screens: sign in, animation library, keyframe upload, motion-plan review, generation status, and result.
- A separate Wave-Line lab with pitch, relief, drift, and pointer controls.
- Responsive layout, keyboard-accessible screen navigation, and reduced-motion handling.
- The Wave-Line canvas converts a grayscale sample illustration to tone-weighted, horizontal wavy strokes. It is a visual study; actual uploaded/generated drawings remain unmodified.

## Direction

An editorial animation workspace: warm mineral paper, deep graphite, fine rules, a restrained oxide-red action color, and an oversized serif for hierarchy. The interface uses square corners, quiet metadata, and generous stage space. It avoids ornamental gradients, pill-heavy UI, generic blobs, and fake GPU progress.

All content and interactions are illustrative. Authentication, file storage, parsing, inference, MP4 rendering, and downloads are not connected to backend services. Unknown upload limits and generation metadata remain unclaimed.
