# Ten-week roadmap

All weeks are planned relative to the course start date (TODO). Milestones depend on consent, compute, and pilot feasibility. The long-term dataset target is not a ten-week completion promise. This repository initializes the foundation only.

| Phase 4 — Testing & Documentation | 10 | Final benchmark; documentation; demo video; GitHub v1.0; final presentation | Held-out evaluation, course report, tagged release and presentation |

## Feasibility gates

Before capture, approve consent and permitted usage. After the pilot, review pairing/stylization quality and split feasibility. Before fine-tuning, establish a runnable baseline and compute budget. Select models using validation evidence; reserve the held-out test set for final evaluation. If language conditioning or serving exceeds available resources, reduce scope explicitly and report the limitation rather than inventing results.
